# Changelog

All notable changes to GW2 GolemRespawn will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## 0.2.0

### Added

- **Center Mouse** setting: optionally moves the cursor to the screen center after each action sequence
- **Experimental Fight Logic** setting: dynamically shows/hides buttons based on combat state — hides Respawn while in combat, shows it only after exiting combat since the last reset
