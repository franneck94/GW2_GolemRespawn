# GW2 Golem Respawn Tool

Have you ever fat-fingered the "Clear Golem" instead of the "Respawn Golem"  button like me?
Then great news, this addon automates it.
It works by just mouse-clicks, no memory reading etc.

The addon will handle:

0. Only active in Golem Training Area
1. Press f to interact 
2. Remove Current Golem
3. Spawn new Golem
4. Position mouse in the middle of the screen

Code: https://github.com/franneck94/GW2_GolemRespawn
BETA DLL: https://github.com/franneck94/GW2_GolemRespawn/releases/tag/0.1.0
Just download the DLL and copy it in your addons dir.

Currently tested for:
WQHD
